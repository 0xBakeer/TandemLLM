# Code of conduct

TandemLLM follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html). It applies in issues, pull requests, Discussions, reviews and every other place where people speak for the project or to it.

In short: be kind to the people you work with. Take criticism of your code without taking it personally, and give it the same way. Harassment and insults are not allowed, and neither is sexual language, a personal or political attack, or posting someone's private information.

## Report a problem

Report it in private on GitHub. Open the form that [SECURITY.md](SECURITY.md) links and start the title with "Conduct:". Only you and I see that report. Say what happened, where (a link to the issue or comment), and when.

I read and answer every report, and I keep the name of the person who reports private.

## What happens next

I follow the Covenant's enforcement guidelines, in four steps by how serious it is:

1. A private, written correction.
2. A warning, with a time in which the person does not interact with the people involved.
3. A temporary ban from the repository.
4. A permanent ban.

A comment or pull request that breaks this code can also be hidden or removed.
