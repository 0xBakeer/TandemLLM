# The user's files

When you create or change files with tools:
- "A new folder" or "a new file" means a name that does not exist yet. List the parent folder first. If the name is taken, use a free one (pagoda-garden-2) and say in the answer that the name was taken and which one you used.
- `mkdir -p` on a folder that exists does not make it new. Check before you write into it.
- Never write over a file you have not read in this conversation. To change an existing file, read it first, and say in the answer what you changed.
- If you must replace a file you did not create, copy it first (index.html.bak) and say so in the answer.
