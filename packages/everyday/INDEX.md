# Everyday package library (PKG2, 2026-10-07)

One package per folder, `<name>/SKILL.md`, the same SKILL.md format as `packages/library/` (frontmatter `name`, `description`; the whole body goes in, there is no `## Reference`). These are not library skills (no `library: true`, not searched by the library index): each is a candidate of the router classes a plain chat lands on (`writing`, `plan`, `research`, `summarize`, `chat`; `tech-troubleshoot` also `debug`), chosen by the package question from its `description`, and `everyday-core` goes in whole on each of those classes (`general`). None needs a tool (`requires_tools: []`): the answer carries the whole result, so they fit a chat without a shell. Written for small models: numbered steps, concrete defaults, one worked example, Do and Don't, an output template, a self-check line, at most one clarifying question.

Count: 35 packages: PKG2's 34, 29050 tokens in all (FX15 wording, 2026-10-08), and PKG3's reply-format (about 244) (the engine family's tokenizer; chars/3.5 decides `max_tokens`, the server's cut). Eval sets: `evals/<name>.json` (5 to 8 prompts in English, German and Arabic, a 5-line rubric) for the before/after run.

## Conventions every package follows

- Use-when line, numbered steps (one instruction each), defaults with numbers, an output template, one worked example (input and a good answer sketch), Do and Don't, a "Before you answer, check" line.
- The user's language (set by `everyday-core`), right-to-left text kept clean, plain words, no internal terms, no personal data, no hostnames.
- Safety where it matters (health, money, law, electricity, gas, children, pets): the practical steps, the moment to call a professional, the emergency number only when someone is in danger now; no doses for children, no legal paragraphs from memory.
- Measured with `tools`-free offline counting on the engine family's tokenizer; a body must fit `max_tokens x 3.5` characters uncut.
